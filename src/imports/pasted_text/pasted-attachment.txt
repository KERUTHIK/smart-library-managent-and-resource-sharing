Design and build a complete modern responsive web application called **“LibSync” — Smart Centralized College Library**.

The product is a centralized digital library platform for a college/institution where multiple department libraries are connected into one system.

The application has 3 user roles:

1. ADMIN
2. DEPARTMENT LIBRARIAN
3. STUDENT / STAFF

After a single sign-in, automatically route the user to the dashboard corresponding to their role. Do not make users manually select their role.

The design should look like a premium modern SaaS product for an educational institution — NOT like an old-fashioned library management system.

## DESIGN STYLE

Use:

* Modern SaaS dashboard aesthetic
* Clean, minimal, professional UI
* Academic + technology visual identity
* Deep navy/indigo as the primary brand color
* Teal/cyan as a secondary accent
* White cards
* Very light gray page background
* Dark navy text
* Subtle borders and shadows
* Rounded corners around 10–14px
* Clean modern typography such as Inter
* Consistent 8px spacing system
* Clear visual hierarchy
* Modern line icons
* Accessible contrast
* Responsive layouts for desktop, tablet and mobile

Avoid:

* Excessive gradients
* Excessive glassmorphism
* Huge decorative illustrations
* Cluttered screens
* Old-fashioned table-heavy library interfaces
* Excessive colors

Create a reusable design system with:

* Primary / secondary / success / warning / danger colors
* Typography styles
* Buttons
* Inputs
* Search bars
* Cards
* Tables
* Badges
* Tabs
* Dropdowns
* Modals
* Toast notifications
* Sidebar navigation
* Top navigation
* Book cards
* Status indicators
* Empty states
* Loading states

Use realistic sample data throughout the interface.

# IMPORTANT UX FLOWS

Design these complete user journeys:

FLOW 1:

Student searches for book
→ Opens book
→ Sees physical copy unavailable in own department
→ Sees copy available in another department
→ Requests physical book
→ Librarian approves
→ Inter-department transfer begins
→ Student receives notification
→ Student picks up book
→ Book appears in My Books
→ Due date is displayed
→ Student returns book
→ Status changes to Returned

FLOW 2:

Librarian uploads PDF
→ AI extracts metadata
→ Librarian reviews metadata
→ Librarian edits if necessary
→ Book published
→ Students can discover e-book

FLOW 3:

Student opens study folder
→ Adds books
→ Reads e-books
→ Opens AI assistant
→ Asks question
→ AI answers using library resources
→ AI shows book/chapter sources
